# Grabber智能代理架构设计文档

## 概述

本文档描述了Grabber项目中突破性的LLM驱动智能代理架构。该架构实现了从传统编程思维向AI原生思维的重要转变，通过Gemini自动函数调用机制，构建了一个真正智能的购物助手系统。

## 核心架构原理

### 1. LLM-as-Recommendation-Engine 范式

**传统方式（已废弃）：**
```python
# 古老的关键词匹配思路
if "渴" in user_input:
    return find_drinks()
elif "饿" in user_input: 
    return find_food()
```

**AI原生方式（当前架构）：**
```python
def buy_product(user_query: str) -> dict:
    """让LLM本身成为推荐引擎，理解复杂语义和多维需求"""
    context = gather_shelf_context(user_query)
    recommendation = llm_analyze_and_recommend(context)
    return execute_recommendation(recommendation)
```

### 2. 自动函数调用（Automatic Function Calling）

利用Gemini的原生自动函数调用能力，实现多步骤工具链的无缝组合：

```python
# 用户："我要买苹果"
# Gemini自动分解为：
# 1. scan_shelf() -> 扫描货架
# 2. buy_product("苹果") -> LLM分析推荐 -> 抓取苹果
```

**关键优势：**
- 无需手动编排工具调用顺序
- 支持复杂的依赖链
- 自然语言驱动的工作流

### 3. 三层架构设计

```
用户自然语言 -> Gemini Agent -> 工具函数库 -> 硬件控制器
     ↑              ↑              ↑             ↑
  语义理解      智能编排        标准化接口      底层硬件
```

## 核心组件

### 1. GeminiAgent (intelligence/gemini_agent.py)

**职责：**
- 自然语言理解和对话管理  
- 自动函数调用协调
- 错误处理和重试机制

**关键特性：**
- 支持手动和自动两种函数调用模式
- 详细的系统指令包含完整任务执行原则
- 异步API调用带指数退避重试

### 2. 工具函数库 (intelligence/robot_tools.py)

**设计原则：**
- 每个函数返回标准化格式：`{"success": bool, "message": str, "error": str}`
- 函数名和文档字符串作为AI理解的主要接口
- 同步函数设计，兼容自动函数调用

**核心工具：**

#### 基础工具
- `scan_shelf()` - 货架扫描和初始化
- `find_item(item_name)` - 精确商品查找
- `grab_item(item_name, position_id)` - 物理抓取操作

#### 智能工具  
- `buy_product(user_query)` - **革命性LLM驱动购买函数**
- `find_items_for_need(user_need)` - 语义需求匹配
- `get_checkout_summary()` - 购物车管理

#### buy_product() - 核心突破

```python
def buy_product(user_query: str) -> dict:
    """
    大模型驱动的通用智能购买函数
    
    理解任何形式的购买需求：
    - 商品名称："苹果"、"可口可乐"
    - 需求描述："我渴了"、"解渴的东西"、"便宜的饮料" 
    - 位置描述："第一层第二个"、"可口可乐旁边的"
    - 复合条件："便宜的解渴饮料"、"提神又不贵的"
    
    内部使用大模型分析用户意图，结合货架信息智能推荐最佳商品
    """
```

**内部流程：**
1. **上下文收集** - 货架布局 + 商品描述 + 用户需求
2. **LLM分析** - 结构化prompt让AI分析推荐策略  
3. **执行推荐** - 自动完成抓取和放置操作

### 3. 语义商品数据库 (intelligence/world_state.py)

**设计理念：** 丰富的语义描述替代简单分类

```python
"可口可乐": {
    "price": 3.5,
    "description": "经典碳酸饮料，红色易拉罐装，330ml，甜味汽水，解渴提神，含咖啡因，气泡丰富，冰爽畅快"
}
```

**支持的智能匹配：**
- 功能需求："解渴" -> 水、饮料类商品
- 价格敏感："便宜的" -> 价格排序推荐
- 复合条件："便宜的解渴饮料" -> 多维度分析

## 技术实现要点

### 1. 同步函数设计

**关键约束：** Gemini自动函数调用不支持异步函数

**解决方案：**
```python
def buy_product(user_query: str) -> dict:
    # 同步函数内部处理异步调用
    result = asyncio.run(llm_analyzer.process_text(prompt))
```

### 2. 错误处理模式

**标准化返回格式：**
```python
{
    "success": bool,
    "message": str,    # 用户友好的描述
    "error": str,      # 技术错误信息（当success=False时）
    # ... 其他业务数据
}
```
